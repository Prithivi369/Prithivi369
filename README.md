## Selected Projects

### ▪ Vector Database from Scratch

`C++` `HNSW` `KD-Tree` `Vector Search` `RAG`

C++ vector database implementing **HNSW, KD-Tree, and brute-force search** with multiple distance metrics and benchmarking. Also includes an HTTP API and a RAG pipeline combining vector retrieval with embeddings and LLM generation.

### ▪ NetScope: Deep Packet Inspection System

`C++` `TCP/IP` `PCAP` `TLS` `Multithreading`

Deep packet inspection engine operating directly on captured network traffic. Implements **TCP stream reconstruction, protocol identification, TLS SNI/HTTP/DNS analysis, and concurrent packet processing** for real-time traffic inspection.

### ▪ AI Interview Preparation Platform

`React` `Node.js` `Gemini AI` `LLM` `Full Stack`

AI-powered interview preparation platform combining a React frontend with a Node.js backend and **LLM-driven workflows** for generating and delivering technical interview preparation experiences.

### ▪ Offline UPI Payment System

`Java` `Spring Boot` `Cryptography` `Distributed Systems` `Idempotency`

Offline payment architecture built around **secure transaction propagation and eventual settlement**. Uses encrypted transactions, replay protection, idempotent processing, and a simulated device-to-device mesh to model reliable offline payment flows.

`Python` `PyTorch` `EfficientNet V2-S` `Computer Vision` `Flask`

Deep learning platform for detecting hidden information in images across multiple steganographic techniques. Includes **custom data generation, training pipelines, model evaluation, cross-tool generalization experiments, and an inference interface**.
